# Formula Tool

## Purpose

A formula tool evaluates formula-like definitions with structured variables.

This is an example of a tool family. It does not introduce a separate execution model.

## Input Examples

- formula code;
- optional formula version;
- variables;
- rounding rules;
- context metadata.

## Output Examples

- result value;
- normalized result payload;
- formula version metadata;
- evaluation trace;
- structured errors.

## Implementation Examples

- expression engine;
- custom JVM implementation;
- spreadsheet-style implementation;
- external service implementation.
