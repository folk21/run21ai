- core models;
- dispatcher interfaces;
- dispatcher chain interfaces;
- tool request/result models;
- tool executor interfaces;
- registry interfaces;
- error/status models;
- audit metadata models;
- unsupported defaults;
- contract tests.

## Exclude

- HTTP API implementation;
- database implementation;
- CLI implementation;
- LLM client implementation;
- expression engine implementation;
- external service implementation.
