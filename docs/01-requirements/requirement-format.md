# Requirement Format

Each requirement file uses this structure:

```text
# REQ-ID: Title

Status: planned | in_progress | done

## Goal

One short goal statement.

## Relationship to Other Requirements

Links to related requirements.

## Functional Requirements

- Requirement statements using MUST, SHOULD, or MAY.

## Acceptance Criteria

- Given ...
  When ...
  Then ...

## Test Cases

- TEST-ID: Expected test scope.
```

The status describes implementation progress.
