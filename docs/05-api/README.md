# API Documentation Map

This folder describes the HTTP contract.

- [API Overview](api-overview.md)
- [OpenAPI Contract](openapi.yaml)

When the REST API backend is running, open the interactive browser documentation at:

```text
http://127.0.0.1:8080/docs
```

The served OpenAPI document is available at:

```text
http://127.0.0.1:8080/openapi.yaml
```
