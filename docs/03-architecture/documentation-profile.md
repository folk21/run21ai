# Documentation Profile

Run21AI uses a lightweight spec-as-code profile:

- arc42-lite architecture structure;
- C4-style context and container views;
- ADRs for architecture decisions;
- OpenAPI for HTTP contracts;
- JSON Schema 2020-12 for structured payloads;
- BDD-style acceptance criteria;
- requirement-to-test traceability;
- generation packs for AI-assisted implementation.
